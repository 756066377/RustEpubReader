# RustEpubReader

**v1.0.20** · Windows 64 位隐蔽 EPUB 阅读器

本仓库只保留 **Windows x86_64** 桌面端，并针对“隐蔽阅读 / 办公摸鱼”做了调整。上游能力已同步到 `zhongbai2333/RustEpubReader` v1.0.8。

## 下载

从 [GitHub Releases](https://github.com/756066377/RustEpubReader/releases/latest) 下载：

- `RustEpubReader-Win64-v1.0.20.exe`

也可以在 [Actions](https://github.com/756066377/RustEpubReader/actions) 里取最新 `windows-desktop-build` 产物（开发构建，文件名带分支名）。

## v1.0.20 更新

- 修复目录切换到未加载章节时一直停留在“正在加载章节”的问题
- 加载 worker 已扫描过目标章节时，会自动排队并重新加载目标，不再漏加载
- 继续保持单 worker，避免高速目录点击创建大量 EPUB 文件句柄

v1.0.17 修复了按需加载模式下目录跳转的定位时序，v1.0.18-v1.0.19 修复了加载任务和恢复位置问题。

## 隐蔽阅读特性

- **无标题栏窗口**  
  主窗口移除了 Title Bar，视觉上更干净，也更不容易一眼看出是阅读器。

- **任务栏不显示图标**  
  打开阅读器后不会在任务栏单独挂一个常规应用入口。

- **Boss Key / 摸鱼快捷键**  
  支持全局隐藏 / 显示阅读器，用于快速收起窗口。

- **快捷键可捕捉修改**  
  不需要手动输入字符串，点击修改后直接按键即可设置。

- **支持单键和组合键**  
  默认是 `F1`，也支持组合快捷键。  
  为了尽量减少与其他软件冲突，单键模式限制为 `F1-F12`。

- **快捷键冲突检测**  
  Windows 下通过系统热键注册机制处理，如果快捷键已被其他程序占用，会直接提示冲突。

- **阅读界面默认收起 Chrome**  
  选项栏、目录、设置等默认隐藏。  
  按 `F2` 只显示选项栏；目录 / 设置等需要点选项栏里的按钮。再按 `F2` 会把选项栏和这些窗口一起收起。

- **阅读窗口始终置顶**  
  进入阅读页后窗口会保持在最上层，避免点击其他软件后阅读器被压到后面。

- **任意空白区域拖动窗口**  
  由于没有标题栏，现在可以在阅读器的空白区域直接拖动窗口位置。

- **四周边缘可调整大小**  
  鼠标悬停到窗口边缘或四角时，可以像普通窗口一样拖拽缩放。

- **背景透明度更适合摸鱼场景**  
  调整的是阅读背景层，而不是把整窗连同文字一起做淡化，目标是让文字保持可读、背景自然融入桌面。

- **瀑布流阅读，隐藏滚动条**  
  只保留滚动模式，滚轮 / 触控板可用，滚动条默认不显示。

## 常用快捷键

- `F1`  
  全局隐藏 / 显示阅读器（默认，可在设置中修改）

- `F2`  
  显示 / 隐藏阅读界面：
  - 第一次：只显示选项栏
  - 第二次：收起选项栏，并关闭目录、设置等功能窗口

- 滚轮 / 触控板  
  连续滚动阅读，不再用 `A` / `D` 或方向键切章、翻页

## 阅读能力

- EPUB 打开与书库记录
- 块级阅读进度保存，并支持跨设备同步
- 瀑布流滚动阅读，支持连续跨章节
- 背景色、背景图、字体、字号、标题倍率、字体颜色调整
- TTS 连续朗读与全书朗读完毕状态
- 命令行直接打开 `.epub` / `.txt`
- 中文 / English 界面

## 构建

本项目在 GitHub Actions 上编译 Windows 发行包。本地如需自行构建：

```bash
cargo build --release -p rust_epub_reader
```

推送 `main` 或打 `v*` 标签后，Actions 会生成 `RustEpubReader-Win64-<ref>.exe`。  
打 `v*` 标签还会自动发布 GitHub Release。

## 当前定位

这不是一个追求“全平台统一体验”的阅读器分支。  
它现在更像是一个专门为 Windows 办公环境优化的隐蔽 EPUB 阅读器。

如果你的目标是：

- 低暴露
- 快速隐藏
- 阅读界面尽量干净
- 在桌面环境中更自然地悬浮阅读

这个分支就是按这个方向做的。
